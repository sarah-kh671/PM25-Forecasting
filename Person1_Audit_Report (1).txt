PERSON 1 — DATASET AUDIT AND CLEANING REPORT Project: PM2.5 Forecasting
Dataset used: combined_gee_pm25.csv

1.  DATASET OVERVIEW The selected file is combined_gee_pm25.csv, which
    combines ground-based PM2.5 measurements with daily
    satellite/reanalysis and meteorological features.

Original dataset size: 41,718 rows and 15 columns. Date range:
2016-11-25 to 2026-04-06. Columns: date, datetime_utc, id, latitude,
longitude, temperature_celsius, pressure_mb, wind_u, wind_v, NO2, CO,
O3, AOD, pm25, sensor_name.

The dataset description states that PM2.5 ground measurements come from
OpenAQ and environmental features are extracted using Google Earth
Engine. Dates are in UTC. Coordinates use WGS84.

2.  VARIABLES AND UNITS

-   PM2.5: µg/m³ (target variable).
-   Temperature: °C.
-   Pressure: hPa.
-   Wind components (wind_u and wind_v): m/s.
-   NO2, CO and O3: mol/m².
-   AOD: dimensionless.
-   Latitude and longitude: WGS84 degrees.

3.  MISSING VALUES AND DUPLICATES In the original combined dataset:

-   NO2: 2,410 missing values.
-   CO: 2,410 missing values.
-   O3: 2,451 missing values.
-   Other columns, including PM2.5: no missing values.
-   Exact full-row duplicates: 0.

The missing values in NO2, CO and O3 are consistent with the dataset
documentation, which mentions gaps caused by cloud cover.

4.  PM2.5 CLEANING The project instructions require removing rows where
    PM2.5 is missing, less than or equal to zero, or greater than or
    equal to 500.

Cleaning results: - Original rows: 41,718. - Missing PM2.5: 0. - PM2.5
<= 0: 727 rows. - PM2.5 >= 500: 8 rows. - Total removed: 735 rows. -
Rows remaining: 40,983.

The original source file was preserved. The cleaned data was saved
separately as cleaned_pm25.csv.

5.  DATE, STATION AND COORDINATE CHECKS In the cleaned dataset:

-   Unique station/location IDs: 95.
-   Unique sensor names: 91.
-   Unique coordinate pairs: 95.
-   Unique dates: 2,299.
-   Repeated date + station ID combinations: 0.
-   Repeated date + sensor name combinations: 2.

The two repeated date + sensor-name combinations were inspected. They
contained different IDs and coordinates, so they were not treated as
exact duplicates and were retained.

Coordinates: - Latitude range: 36.1333 to 43.5303. - Longitude range:
-5.6635 to 9.1364. - Missing coordinates: 0.

Rows per station: - Minimum: 4. - Median: 442. - Maximum: 1,042.

6.  PRELIMINARY CORRELATION WITH PM2.5 The strongest positive
    correlations observed were:

-   NO2: 0.1593.
-   Pressure: 0.1133.
-   AOD: 0.0942.
-   Wind_v: 0.0595.
-   CO: 0.0415.

The strongest negative correlations observed were: - O3: -0.0872. -
Wind_u: -0.0786. - Latitude: -0.0460. - ID: -0.0346. - Longitude:
-0.0228. - Temperature: -0.0060.

These are preliminary linear correlations only. They do not establish
causation or prove that a variable is free from target leakage.

7.  SOURCE AND LICENSE NOTES The dataset description identifies OpenAQ,
    Copernicus and NASA data sources. It describes OpenAQ as CC BY 4.0
    and the Copernicus/NASA sources as open access. The Kaggle
    dataset-level license field is listed as “Other (specified in
    description)”. Individual source terms should be checked before
    reuse, especially for commercial purposes.

8.  DOCUMENTATION DISCREPANCY AND LIMITATIONS The dataset description
    mentions 125 ground sensors and 100 GEE grid locations. The selected
    combined file contains 95 unique IDs and 91 unique sensor names.
    This difference is recorded as a documentation/file discrepancy; the
    counts were not altered.

The available documentation does not fully specify the construction of
every feature in the combined file. No direct target-derived feature was
identified from the column names, but feature provenance could not be
independently confirmed. Correlation analysis alone cannot rule out
target leakage.

9.  OUTPUT FILES

-   cleaned_pm25.csv — cleaned dataset containing 40,983 rows.
-   cleaning_report.csv — summary of removed and remaining rows.
-   Person1_Audit_Report.txt — this audit report.
